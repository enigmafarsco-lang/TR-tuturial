## تصاویر دقیقاً چه هستند؟

۵۲ تصویر مجزا در متن اصلی با لینک نسبی PNG درج شده‌اند:

- **۸ اسکرین‌شات واقعی از نرم‌افزار اجراشده**: یک نمای کامل JupyterLab، شش برش واقعی از سلول کد/خروجی همان نرم‌افزار و یک گزارش تعاملی Backtesting.py/Bokeh.
- **۴۴ شکل آموزشی**: ۱۶ نمودار/طرح اختصاصی مثل پیپ، هزینه، اهرم، تقویم، حجم، چرخه سفارش و walk-forward؛ ۲۸ نقشه مفهومی درس‌ها.

**نرم‌افزار واقعی است؛ داده‌ها ساختگی‌اند.** هیچ تصویر حساب واقعی یا عملکرد واقعی بازار معرفی نشده است. هیچ تصویر AI-generated به‌عنوان اسکرین‌شات معرفی نشده است. اسکرین‌شات MT5 یا TradingView در این نسخه نیست؛ محیط کارگزار هنوز انتخاب نشده است. آموزش این نسخه ابزار پژوهشی را پوشش می‌دهد، نه منوهای یک کارگزار تأییدنشده.

فهرست دقیق نوع، مسیر و توضیح هر تصویر: [manifest.json](images/manifest.json). نسخه نرم‌افزارها و روش ثبت: [capture-info.json](software/capture-info.json).

## محدوده اعتبار

این پروژه سند و آزمایش ابزار پژوهش است؛ ربات معامله زنده، توصیه مالی شخصی، داده تاریخی تأییدشده یا اثبات سود نیست. پذیرش حساب با اطلاعات واقعی، مقررات، هزینه، تأمین وجه و API باید مستقل تأیید شوند. توقف قیمت تضمین زیان محدود نیست. AI اجازه تغییر سیاست ریسک یا دسترسی به برداشت ندارد.

## بازتولید متن و مثال‌ها

از ریشه مخزن:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements-research.txt
.venv/bin/python scripts/create_lab.py
.venv/bin/python scripts/build_book.py
.venv/bin/python scripts/chart_diagrams.py
```

در Windows مسیر اجرایی محیط مجازی `.venv\Scripts\python.exe` و `.venv\Scripts\pip.exe` است. برای مشاهده نوت‌بوک می‌توانید `jupyter lab` را از محیط فعال اجرا کنید. توکن Jupyter را عمومی نکنید.

ابزار اختیاری مرورگر با `npm ci` و نسخه‌های قفل‌شده `package-lock.json` نصب می‌شود. پس از اجرای سرور محلی، `npm run render:book` شکل‌ها و PDF را بازسازی می‌کند. بازسازی PNG شکل‌ها و PDF به Chromium و Playwright نیاز دارد. اسکریپت `scripts/render_book.cjs` از `playwright-core` و `@sparticuz/chromium` استفاده می‌کند و انتظار دارد سرور محلی روی پورت ۳۰۰۰ فعال باشد. در محیط استاندارد باید وابستگی‌های سیستم Chromium فراهم باشند؛ `LD_LIBRARY_PATH` استفاده‌شده در محیط ساخت، تنظیم عمومی همه سیستم‌ها نیست. اسکرین‌شات‌های فعلی از قبل در مخزن موجودند و برای مطالعه نیاز به بازتولید نیست.

اسکریپت `capture_software.cjs` مخصوص محیط ساخت است: Jupyter محلی روی پورت ۸۸۸۸ و توکن در فایل خارج از مخزن `/tmp/atlas-jupyter-token`. این مسیر قرارداد ابزار ثبت تصویر است، نه اطلاعات ورود یک کارگزار. اسکریپت هیچ توکنی را داخل تصویر یا خروجی ذخیره نمی‌کند. برای محیط دیگر، URL و روش احراز هویت را مطابق مستندات امن تنظیم کنید.
