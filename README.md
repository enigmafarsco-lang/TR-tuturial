## چه چیزی اضافه شده است؟

۵۲ درس، ۵۲ تصویر درج‌شده در Markdown، **۸ اسکرین‌شات واقعی JupyterLab و Backtesting.py/Bokeh**، ۱۶ نمودار توضیحی اختصاصی و ۲۸ نقشه مفهومی. هر درس هدف، توضیح، مراحل و تمرین دارد. تعداد صفحات فقط یک ادعا یا شماره تیتر نیست؛ فایل PDF واقعاً ۵۲ صفحه دارد و با آزمون بررسی می‌شود.

**اسکرین‌شات واقعی ≠ داده واقعی:** داده‌ها، معاملات و نتایج مثال‌ها ساختگی‌اند. تصاویر MT5/TradingView یا حساب کارگزار ارائه نشده‌اند؛ آموزش مصور ابزارهای پژوهشی واقعی همراه است. این مخزن ربات اجرایی یا اثبات سودآوری نیست.

پایلوت EUR/USD برای محدودکردن پیچیدگی انتخاب شده؛ مقصد، سامانه چندبازاری است. پردازش شبانه‌روزی به معنی معامله دائمی نیست. هدف حفظ سرمایه است، اما تضمین حفظ اصل پول یا سود وجود ندارد.

## مشاهده محلی

```sh
python -m http.server 3000 --bind 0.0.0.0
```

سپس روی همان دستگاه `http://localhost:3000` را باز کنید. برای مطالعه Markdown/PDF نصب وابستگی لازم نیست. جهت اجرای نمونه‌های پژوهشی و بازتولید، [راهنمای فنی](docs/README.md) را ببینید.

## بررسی‌ها

```sh
node tests/calculator.test.js
python tests/check_document.py
.venv/bin/python tests/check_book.py
```

تست کتاب به وابستگی `pypdf` در `requirements-research.txt` نیاز دارد. تست‌ها صحت ساختار و محاسبات نمونه را بررسی می‌کنند، نه سودآوری یا اجرای کارگزار.
