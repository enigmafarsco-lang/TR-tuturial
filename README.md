# اطلس — آموزش تصویری سامانه معاملاتی هوشمند چندبازاری

راهنمای فارسی راست‌به‌چپ برای طراحی سامانه‌ای که شبانه‌روزی خبر و داده را پایش می‌کند، ولی فقط مطابق قواعد و محدودیت ریسک معامله می‌کند.

**پایلوت آموزشی: EUR/USD. مقصد معماری: چندبازاری.** انتخاب پایلوت به معنی اثبات سودآوری یا کم‌ریسک‌ترین بازار بودن نیست.

## مشاهده

فایل [index.html](index.html) را دانلود و در مرورگر باز کنید؛ فایل‌های `assets` باید کنار آن باقی بمانند. یا در ریشه مخزن اجرا کنید:

```sh
python -m http.server 3000 --bind 0.0.0.0
```

سپس `http://localhost:3000` را روی همان دستگاه باز کنید. صفحه بدون نصب وابستگی و بدون دریافت فونت یا کتابخانه خارجی اجرا می‌شود. برای PDF دکمه «چاپ / ذخیره PDF» و گزینه Save as PDF مرورگر را انتخاب کنید؛ PDF از پیش تولید نشده است.

## فصل‌ها

1. نقشه یادگیری و پایلوت EUR/USD
2. معماری داده، خبر، تحلیل، ریسک، اجرا و ژورنال
3. واحد، پیپ، اسپرد، مارجین و اندازه سفارش
4. نمودار و فرضیه قابل‌آزمایش
5. خبر، تلگرام، شبکه اجتماعی و دفاع در برابر تزریق دستور
6. محاسبه حجم و مدیر ریسک مستقل از AI
7. پنل آموزشی و مراحل اجرای دمو
8. نشت اطلاعات، بک‌تست و فورواردتست
9. برنامه ساخت نرم‌افزار و پرامپت کدنویسی
10. گسترش به بازارهای دیگر
11. منابع رسمی و مستندات

## تصاویر و محدودیت‌ها

سه تصویر SVG شامل معماری، نمودار فرضی و خط پردازش خبر، به‌همراه پنل HTML بازسازی‌شده وجود دارد. **هیچ‌کدام اسکرین‌شات واقعی کارگزار، قیمت زنده یا نتیجه بک‌تست نیستند.** بخش اسکرین‌شات واقعی منوها بعد از انتخاب پلتفرم باید اضافه شود.

این مخزن سند آموزشی و ماشین‌حساب تمرینی است، نه کد ربات اجرایی. پوشه‌بندی نرم‌افزار داخل سند صرفاً پیشنهاد معماری است. هیچ سفارش، اتصال حساب، کلید API یا وعده سود وجود ندارد. شرایط جاری حساب، اقامت واقعی، مجوز، واریز/برداشت و API قبل از اجرا باید بررسی شوند. بازارهای خارجی ریسک تحریم، مسدودی، طرف مقابل، ارز و اجرای سفارش دارند.

## فایل‌ها

- `index.html`: سند اصلی و نسخه چاپی
- `assets/*.svg`: نمودارهای محلی آموزشی
- `assets/app.js`: ماشین‌حساب ساده واحد EUR/USD، بدون اهرم، با سقف مواجهه
- `tests/calculator.test.js`: آزمون‌های ماشین‌حساب
- `tests/check_document.py`: بررسی ساختار و دارایی‌های سند

## تست‌ها

```sh
node tests/calculator.test.js
python tests/check_document.py
```

این تست‌ها ساختار سند و محاسبات نمونه را بررسی می‌کنند؛ آزمون سودآوری، اجرای کارگزار یا اعتبارسنجی مرورگری نیستند.
